Super.img Unpacker

Extracts Android dynamic-partition super.img images (sparse or raw, LP/liblp metadata) entirely client-side — nothing is uploaded anywhere. Partitions stream straight to a folder on your device via the File System Access API, so multi-gigabyte images don't need to fit in memory.

4. Security scan — find Device Administrator APKs read-only, scan only

Scans the selected partitions' file systems directly (ext4 or EROFS, auto-detected) for .apk files and checks each app's manifest for Device Administrator capability — the mechanism used by unremovable "security"/MDM-style bloatware as well as legitimate MDM apps. This only reads and reports; it does not modify, strip, or repack any partition.
